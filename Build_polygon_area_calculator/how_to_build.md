# Polygon Area Calculator

This project is an implementation of **Object-Oriented Programming (OOP)** using Python to create a calculator for the area and basic properties of **Rectangle** and **Square** shapes.

## Features

- Create `Rectangle` objects with `width` and `height`.
- Create `Square` objects with a `side` length.
- Calculate:
  - Area
  - Perimeter
  - Diagonal
- Display the shape using `get_picture()`.
- Calculate how many of one shape can fit inside another using `get_amount_inside()`.
- Utilize **inheritance**, with `Square` as a subclass of `Rectangle`.
- Implement **method overriding** for `set_width()` and `set_height()` to ensure a `Square` always maintains equal `width` and `height`.

## OOP Concepts

This project applies several fundamental OOP concepts:

- **Class & Object**
- **Inheritance**
- **Method Overriding**
- **Encapsulation via attributes and methods**
