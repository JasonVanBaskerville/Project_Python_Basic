## Planet Class

This program is an **Object-Oriented Programming (OOP)** exercise that involves creating a `Planet` class with the attributes `name`, `planet_type`, and `star`.

### Features

* Validates input to ensure `name`, `planet_type`, and `star` are **strings and not empty**.
* `orbit()` → displays a message indicating that the planet is orbiting a star.
* `__str__()` → provides a human-readable text representation of the `Planet` object.
* Creates several planet objects, such as Earth, Mars, and Jupiter.

This program practices the use of **classes, constructors (`__init__`), instance attributes, methods, `__str__()`, `TypeError`, and `ValueError`** in Python.
